# Federation/import module handover

This module owns import, source memory, connectors, exports and portability.

Routes are mounted by core. `imports/jobs.ts` retains originals, canonical actor-bound keys, staged R2 media, failure reports and atomic D1 publication through content/structured planners. Canonical search reads those records synchronously. Importing an existing page uses destinationPageId/expectedRevisionId/mode append or children. Current retry preserves the archive; interrupted claims recover after fifteen minutes. Named source identities become historical members/groups; source general grants remain container-scoped. No external source principal is activated and no anonymous exposure is republished. Unresolvable CSV-view links are retained as text and named as unmapped, never fabricated records. Source attachment sharing creates separately page-governed file rows.

`connectors/README.md` records exact supported personal OAuth providers, preparation, scopes, token custody, current-access checks and honest GitHub effect limitations. `source-memory/service.ts` resolves exact retained passage/revision references or content-free tombstones; staged unpublished versions cannot be cited. `source-memory/worker.ts` supplies bounded refresh/scheduling handlers. `searchSources` supplies live-ACL-checked source passage retrieval.

Portability uses explicit table registry plus installed-column comparison, JSON data rather than archive SQL, SHA-256 manifest/file integrity, encrypted secrets exclusion, owner authentication and setup-owner-only empty restore. R2 originals stage before one D1 publish; imported external authority/schedules are disabled and sessions invalidated. New schema tables must be intentionally added to `portability/tables.ts`; missing registration fails visibly. Source credentials, auth nonce/session/invitation transport records and stored operation responses are excluded. Uploaded files and retained original imports are included. Derived prior export archives are not recursively included.

Operator command: `node src/core/features/portability/command.mjs backup|restore ARCHIVE.zip`, with `SLATE_APP_URL` and authenticated owner `SLATE_SESSION_COOKIE`. It never prints the cookie and backup exclusive-creates a mode0600 file. Fresh restore requires the authenticated setup owner email in the archive. Scoped readable export `/api/exports/readable` supports page/descendants/container + markdown/html/pdf, original media and CSV plus `slate-readable` reimport manifest. PDF uses bundled OFL Noto fonts; unsupported glyphs fail explicitly instead of replacing text.

Verification: `pnpm test:imports`, `pnpm exec vitest run --config tests/flagship/federation/vitest.config.ts`, and `pnpm typecheck`. Incumbent export fixtures contain synthetic personal identities while preserving formats and mapping edge cases. The suites exercise real local Worker/D1, archive validation and restoration, current session boundaries, OAuth state, provider failure/revocation, readable output, rollback/retry and existing-page append/CAS. Provider transport fixtures do not establish live-provider acceptance.
